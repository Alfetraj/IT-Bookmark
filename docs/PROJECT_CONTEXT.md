# Project Context

## IT Bookmark
An enterprise-grade, self-hosted bookmark management platform, inspired by Linkwarden, but built independently with a custom Clean Architecture stack.

## Tech Stack
- **Frontend:** React 19, Vite, TypeScript, Redux Toolkit, TanStack Query, React Router v7, SCSS Modules.
- **Backend:** Node.js, Express, TypeScript.
- **Database:** Supabase PostgreSQL.
- **Infrastructure:** Docker, Docker Compose.

## Goals
Provide a modern bookmark management experience with:
- Nested collections
- Tagging and categories
- Advanced search
- Scraping metadata and favicons
- Import/Export
- Dark/Light mode
